# PayCalculator

A simple web application to calculate total hours worked, remaining hours, estimated pay based on user inputs, and view a corresponding week-by-week calendar.

## Live Application

You can access the live application here:
[https://krishna-glitch.github.io/PayCalculator/](https://krishna-glitch.github.io/PayCalculator/)

## How to Use

1.  Enter the Start Date, End Date, and Hours Worked Per Week.
2.  Optionally, enter the Hourly Rate ($) and a Total Hours target.
3.  The results in the blue box will update automatically as you enter valid data.
4.  Use the "<" and ">" buttons above the calendar to view different years.
